# Security contract

V1 is a single-user local Studio, not a multi-tenant SaaS. One process owns background workers. Run on loopback by default; a configured `STUDIO_TOKEN`, HTTPS and an appropriately restricted reverse proxy are required for network exposure. API and artifacts require a bearer token or an HttpOnly same-site session when a token is configured. Cross-origin mutations are rejected. Sessions expire with cookie/application lifecycle. Browser DOM rendering escapes all project text. Generated previews use an opaque sandbox origin and an eight-hour, unguessable read-only capability restricted to generated HTML/CSS/JavaScript/images/fonts. Preview capabilities cannot access APIs, server code, databases or evidence, and expire on process restart. Treat a shared preview URL as temporary public-artifact read access; untrusted reference HTML is downloadable text, never executed in the Studio origin.

Secrets live only in environment variables. Claude receives a bounded strategy/rules/sitemap payload, not raw uploads or contact data. Provider failure messages omit keys/request bodies. Generated websites/packages never contain environment configuration or API credentials. Avoid entering secrets into project briefs: authorized user text is project content, not a secret vault.

Uploads have byte and pixel limits, verify image bytes against extensions, sanitize filenames, prevent traversal and reject active SVG/HTML/executable uploads. Original files retain SHA-256 hashes. PDF/text guide extraction is verbatim evidence, not automatic permission to invent page facts. Structured JSON guides use validated requirement/palette/font schemas.

Reference/research requests allow only public HTTP(S), standard web ports and URLs without credentials. All resolved addresses must be globally routable; every redirect is revalidated. Direct HTTP/TLS connections pin the validated IP and preserve hostname verification. The default proxy path also attempts IP pinning. Some managed egress proxies cannot validate pinned TLS identities. **Only on a trusted egress proxy with its own private-destination/DNS-rebinding controls**, configure `STUDIO_TRUST_EGRESS_PROXY=1` to delegate hostname resolution. This opt-in never disables certificate verification or the Engine's public-address/redirect checks. Do not enable it for an untrusted proxy. Browser forensics validates routed resource destinations and blocks service workers/downloads; protect the browser worker with network egress rules for hostile reference sites. V1 is not a hardened hostile-content analysis service.

Contact handoff stores submissions outside the public site directory, validates input, rejects cross-origin requests, applies a bounded local rate limit and never exposes a message-list API. Enquiry delivery is local persistence, not email sending. Use a real mail/CRM integration only after explicitly configuring it, with retention/privacy policy appropriate to the business.

All live publication/domain/paid-service/destructive actions are outside automatic execution. Build preparation and reversible versioned packaging proceed autonomously. No V1 adapter changes a live store or DNS. Recovery verifies source/lock/build hashes before continuing. SQLite revision checks and unique active-job constraints reject conflicting writes.
